# Concise - URL Shortener

**Live Demo**: [https://concise-frontend.onrender.com](https://concise-frontend.onrender.com)

Concise is a scalable, full-stack URL shortening service that allows users to create short, memorable links with optional custom slugs. It features user authentication and provides persistent click analytics tracking for authenticated users.

## 🚀 Key Features

- **Custom Short URLs**: Generate cryptographically secure, collision-resistant 7-character aliases using NanoID, or create your own custom slugs.
- **Click Analytics**: Tracks clicks and usage analytics for links generated by authenticated users.
- **Fast Redirection**: Engineered with indexed MongoDB schemas ensuring O(1) read performance for instantaneous redirection.
- **Secure Authentication**: Robust HTTP-only cookie-based authentication pipeline using JSON Web Tokens (JWT) and bcrypt, mitigating XSS vulnerabilities.
- **Modern UI**: Highly responsive single-page application featuring aggressive data caching for a seamless user experience.

## 💻 Tech Stack

### Frontend

- **React & Vite**: Fast development and optimized production builds.
- **Redux Toolkit**: Centralized, predictable state management.
- **React Query**: Efficient data fetching and aggressive client-side caching.
- **Tailwind CSS**: Rapid, responsive UI styling.

### Backend

- **Node.js & Express**: Scalable RESTful API architecture.
- **MongoDB & Mongoose**: Flexible, NoSQL database with optimized indexing.
- **Authentication**: JWT, bcrypt, and HTTP-only cookies for secure session management.
- **NanoID**: Fast, secure unique identifier generation.
